## 🚀 Featured Projects

### 1. Intelligent Enterprise Knowledge Assistant (IEKA)

An AI-powered document question-answering application that uses Retrieval-Augmented Generation (RAG) to help users retrieve information from PDF documents.

**Technologies:** Python, LangChain, Hugging Face Embeddings, FAISS, Google Gemini API.

- Processes PDF documents for question answering.
- Uses vector search to retrieve relevant document content.
- Combines retrieval with a generative language model.

[![View Repository](https://img.shields.io/badge/View%20Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/sonia071202/Intelligent_Enterprise_Knowledge_Assistant)

### 2. CampScout — Campground Discovery Application

A web application for discovering campgrounds, viewing listings, and managing campground reviews.

**Technologies:** Node.js, Express.js, MongoDB, Mongoose, EJS, Passport.js, Cloudinary, MapTiler.

- Implements user authentication.
- Supports campground listings and reviews.
- Integrates image hosting and map functionality.
