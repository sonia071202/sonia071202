## 🚀 Featured Projects

### 🧠 Intelligent Enterprise Knowledge Assistant (IEKA)

A Retrieval-Augmented Generation (RAG) application that answers questions using information retrieved from PDF documents.

- 📄 Processes PDF documents and splits text into chunks.
- 🔎 Retrieves relevant content using semantic similarity search.
- 🤖 Uses a language model to generate context-aware answers.
- 🧠 Uses embeddings and FAISS for vector-based document retrieval.

**Tech Stack:** Python, LangChain, Hugging Face Embeddings, FAISS, Google Gemini API.

🔗 [View Project on GitHub](https://github.com/sonia071202/Intelligent_Enterprise_Knowledge_Assistant)

### 🏕️ CampScout — Campground Discovery Platform

A full-stack web application for discovering campgrounds, managing listings, and sharing reviews.

- 🏕️ Create, view, update, and delete campground listings.
- 🔐 User authentication and authorization using Passport.js.
- ⭐ Add reviews and ratings for campgrounds.
- 🗺️ Explore locations using interactive maps.
- 🖼️ Upload and manage images using Cloudinary.

**Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, EJS, Passport.js, Cloudinary, MapTiler.

🔗 [View Project on GitHub](https://github.com/sonia071202/Yelp_Camp)
